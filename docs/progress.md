## 本轮反馈

用户真实截图显示字体、边框和控件风格仍显粗糙。当前实现是 Qt Widgets + QSS + 部分自绘，不能将布局重构等同于原生 Windows 产品质感。字体回退、字重映射、深色底边与焦点框、图标和控件混用需要进一步统一；M5 尚未推进。

新增下载布局：保存目录／平台中文名／帖子标题_任务短号_执行短号／原帖顺序编号与标题文件。保留原平铺目录识别，兼容恢复、打开和校验；不搬动历史文件，不覆盖旧输出。
