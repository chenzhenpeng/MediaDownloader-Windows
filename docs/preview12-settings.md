# 预览版 12：设置分区

设置页将应用包、ParseHub 解析组件、执行环境和媒体工具分别呈现。

- 解析组件显示当前组件版本及 ParseHub 版本；其检查按钮只选择解析组件候选。
- 执行环境显示当前环境版本与实际来源；其检查按钮只选择完整运行环境候选。更新解析小包但仍复用随包 worker 时，来源仍显示“随应用提供”。
- 媒体工具分别显示 FFmpeg/ffprobe 和 yt-dlp 的版本与来源，可查看详情。当前仍由执行环境提供，尚未增加本地可执行文件选择入口。
- 自动检查、锁定和恢复放入共用的组件维护区。恢复的是兼容组合，不允许无约束地混搭解析组件和运行环境。
- 应用包版本独立显示。应用包仍通过安装程序升级。

独立检查复用同一套签名、兼容选择和安装机制；手动安装请求同时提交组件类型，后台拒绝与当前候选类型不一致的请求。
