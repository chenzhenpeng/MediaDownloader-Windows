## 实际抖音样本

样本 ID：douyin-user-01，用户提供的公开短链；无 Cookie、无代理。相同作品在两种运行方式下测试，只计 1 个独立样本。

- 源码：解析及完整下载通过，6.828 秒。
- 冻结内核：真实 TaskService 完成预览、重新解析、下载与提交，11.750 秒。
- 文件：17,240,754 bytes，约 16.44 MiB；92.9 秒，576×1024，H.264 + AAC。
- 两份文件 SHA-256 均为 `3f5289db4a46fc30e9a0a0cab60db5d9ef6d3a6a2f5f09cade8e072d3540576b`。
- 首次冻结验证失败，原因是冻结 Python 未按环境变量使用 UTF-8，中文 JSON 输出被客户端拒绝。已显式配置 stdin/stdout/stderr 为 UTF-8，重建后同样本通过，并增加 GBK 父流回归测试。

此结果不代表所有抖音作品均支持，也不代表原视频的最高画质。原始 URL、下载文件与运行数据库保存在被忽略的 `.local/m0`；报告不包含 Cookie 或签名 URL。
