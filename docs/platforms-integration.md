- 连接配置列出全部平台；能力文案来自当前所选内核，不将模块加载通过等同于线上成功。

## 更新边界

适配改动均位于应用自有层，本轮不修改 ParseHub 源码或现有上游补丁集。原有解析器的上游修复仍按固定 SHA、补丁重放、测试与内核发布流程同步。新增平台时平台注册表覆盖测试会提醒缺口，需要同步审查域名与媒体能力；不能静默信任上游任意域名。

## 未完成事项

除已记录的抖音样本和用户小红书反馈外，新增平台尚无完整线上样本矩阵；登录、地区、代理与平台风控仍可能影响实际解析。客户端仍是未签名测试包，正式安装器、生产更新源、干净 Windows 与发行验收尚未完成。
