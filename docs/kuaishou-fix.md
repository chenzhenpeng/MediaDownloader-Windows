# 快手真实样本修复

客户端 0.1.0.dev10；内核 0.1.0.kuaishou-dev10。

用户提供的快手公开短链在旧内核被标为下载完成，但文件只有 13,141 字节，实际是 HLS 播放列表。此记录判定为验收失败，不能作为平台下载成功的证据。

根因是作品响应同时提供了表示层 M3U8 与 photoUrl 完整 MP4，上游先选中了 M3U8。修复优先选择完整文件；不再把播放列表里的第一段当成完整作品。worker 提交前拦截伪装成媒体文件的 HLS、DASH 清单和 HTML 错误页。只有 HLS 的地址目前明确报错，不冒充完成。

快手元数据时长为毫秒，现统一换算为秒。源码 worker 使用 `python -m` 时的重复模块导入也已修复，保证握手在 stdout 而非 stderr。

源码实测已得到 54,364,728 字节的 MP4，FFprobe 确认 282.4 秒、1276×720、H.264 视频与 AAC 音频。最终冻结版复验与测试包信息记录在 review/kuaishou-fix.json。

提供器修复已纳入 0003-platform-boundary.patch 并更新哈希清单；后续同步上游会重放与复验。旧下载文件不自动覆盖，更新后重新下载该任务。
