## 使用和边界

先关闭应用并安装新应用包，再在设置中检查组件更新。正常更新不能降级；回滚只选择已认证的本地组合。更新与回滚不修改下载目录和已保存的 Cookie。

三类 GitHub 构建/发布工作流均已进入主分支；其中 Windows 源码验证和目录续签已在线实际运行成功。应用包、运行环境和解析包的构建/自检本轮在本机完成，不能据此宣称三个完整构建工作流都已在 GitHub 跑过。后续可以分别手动触发这些草稿构建流程。

应用包的升级仍通过安装器进行，尚无应用自动替换器；组件更新器负责 ParseHub 与执行环境。预览安装器尚未取得产品代码签名证书。组件包的 Ed25519 签名与 Windows 安装器代码签名是不同机制。
