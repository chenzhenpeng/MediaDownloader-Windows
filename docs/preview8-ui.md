# Preview 8 界面与图标

这一版延续 WinUI 3 原生控件、Windows 主题和 Mica 材质，统一视觉层级与布局，不增加额外界面运行库。

- 应用标识改为叠放的作品卡片与下载符号。SVG 是源文件，构建时生成 16、20、24、32、40、48、64、128、256 像素图标；窗口、可执行文件、快捷方式和安装器使用同一套资产。
- 页面标题为 28/36、区块标题为 16/24、辅助说明为 13/20；保留 Windows 原生字体回退、焦点样式与交互控件。
- 首页在内容宽度达到 960 DIP 时并排显示输入卡片和解析流程，窄窗口变为上下排列。两种布局都使用可用宽度，不保留无用途的右栏。
- 解析流程显示实际提交数量、处理中数量和成功/失败数量。进行中的步骤使用主题强调色；完成与失败同时用符号和文字表达，不能仅靠颜色辨识。
- 本次解析结果独立成区，结果行统一缩略图、标题、媒体属性、状态与操作按钮；失败原因直接显示在行内。下载历史仍在下载管理中。
- 设置页为同一栅格的图标、名称、说明与右侧控件。下载管理、设置和首页共用标题、卡片、辅助文字及空状态规范。

实际窗口检查通过 computer-use 的 Windows 窗口捕获完成。自动验收覆盖 18 个基础场景和 12 个解析中/成功/失败的浅深色、宽窄窗口场景，结果位于 `review/native/layout-preview8/summary.json` 和 `review/native/states-preview8/summary.json`。解析样例明确用于视觉验收，不代表真实平台解析结果。

安装器延续 Preview 7 的原生 x64 EXE、高压缩与当前用户安装方式。QA 使用独立产品身份、隔离数据库及独立安装互斥量，不关闭或覆盖用户当前运行的正式应用。正式安装器继续检查应用是否运行，要求关闭后才能升级。
