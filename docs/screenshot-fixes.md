# 截图审查修复

客户端 0.1.0.dev11，复用快手修复内核 0.1.0.kuaishou-dev10。

- 已知受影响的旧快手内核 platforms-dev9 历史预览会备份 SQLite 后换算毫秒，标记修复版本并保留原数值，重复启动不再换算。其他版本不猜测时长单位。
- 启动后在后台读取已完成输出的文件头。确认播放列表或 HTML 错误页时，将当前任务标为“文件无效，可重新下载”；结果绑定执行编号及数据修订号，避免覆盖新下载。原文件和原执行报告均保留。缺失、移动或锁定文件不直接判为损坏。
- 首页以简短摘要显示平台数量与类型，展开后保留全部平台和可搜索清单。
- 空队列隐藏无用命令及筛选，保留添加下载；筛选没有结果时保留搜索入口。
- 历史列表增加文件大小与结束时间，选中行增强背景及侧边标记。
- 详情可展开及复制完整标题；文件无效的详情不提供误导性的连接设置入口。
- 设置卡片直接解释未配置更新源；展开导航不再重复提示文字，鼠标点击和键盘焦点分开显示。

285 项测试及 104 项子测试通过，100%、150%、200% 界面检查通过。冻结客户端的旧数据升级与正常记录对照证据见 review/screenshot-fixes.json。

此轮媒体检查针对已知的播放列表和错误网页，不等同于对所有编码损坏进行完整解码。客户端仍为 Qt Widgets 测试版，不代表已经完成正式发行验收。
