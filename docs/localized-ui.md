# 中文界面与紧凑布局修订

客户端 0.1.0.dev12；内核 0.1.0.localized-dev12。

应用统一安装 Qt 官方 qtbase_zh_CN.qm 中文资源，并在构建中显式携带该文件。链接、搜索、保存路径、代理与 Cookie 输入框的 Qt 原生编辑菜单因此显示中文，保留原生撤销、选择、快捷键和禁用状态；密码字段剪切与复制仍禁用。

确认弹窗使用具体中文动作（移除记录、回滚内核、取消任务并退出）和“取消”，默认及 Esc 都取消。移除记录的说明明确保留已下载文件；对话框给出合适的最小内容宽度，避免孤立字断行。

首页减少间隔和输入区高度；最近保存改为“暂无成功下载的作品”。空队列不再保留巨大表格边框，搜索无结果时提供“清除筛选”。详情将状态、错误建议及保存位置置于封面之前，缩小可选封面；无效文件的属性标记为原解析信息。

微信视频号需要元宝登录凭据。现在未配置时会返回 AUTH_REQUIRED 并说明来源，设置页同步显示说明。用户样本已携带完整元宝 Cookie 完成真实解析，返回 1 个 MP4；平台未返回时长和分辨率，本次未执行媒体下载。凭据未写入项目文件、报告或测试包。

286 项测试、104 项子测试通过；100%、150%、200% 下四页界面、中文编辑菜单、密码保护和确认弹窗检查通过。最终冻结包证据见 review/localized-ui-checks.json。
